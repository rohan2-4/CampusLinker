## About the Project

CampusLinker is a web-based campus management portal built for **Skylink Institute of ACS**. It provides a unified platform for students to apply for admission, pay fees, register for exams, and view results — while giving administrators full control over exam creation and result management.

---

## ✨ Features

### Student
- **Registration & Login** — Secure account creation with hashed passwords
- **Admission Form** — Upload photo, ID proof, signature, and marksheet; submit personal and academic details
- **Fee Payment** — Auto-calculated course fees with itemized breakdown; supports multiple payment methods; download PDF receipt
- **Exam Registration** — View and register for upcoming exams filtered by enrolled course
- **Results** — View personal exam results with marks, grade, CGPA, and pass/fail status
- **Social Activities** — Log extracurricular activities
- **Forgot Password** — Email-based password reset flow

### Admin
- **Exam Management** — Create exams with multiple subjects, dates, timings, and marks
- **Result Management** — Enter and update student marks, grades, CGPA, and result status
- **Analytics Dashboard** — Visual charts (line, histogram, pie) showing result trends and pass/fail distribution

## 🛠 Tech Stack

| Layer | Technology |
|---|---|
| Backend | Python · Flask |
| Database | SQLite (via `sqlite3`) |
| Frontend | HTML5 · CSS3 · Jinja2 Templates · JavaScript |
| PDF Generation | ReportLab |
| Auth | Werkzeug (password hashing) |
| UI Components | Custom CSS + Bootstrap-style layout |

> The `package.json` in the repo is a Next.js/React scaffold (generated by v0) and is **not** used by the Flask backend.

## 🚀 Getting Started

### Prerequisites

- Python 3.10+
- pip

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/rohan2-4/CampusLinker.git
cd CampusLinker

# 2. Create and activate a virtual environment (recommended)
python -m venv venv
source venv/bin/activate        # Linux/macOS
venv\Scripts\activate           # Windows

# 3. Install dependencies
pip install flask werkzeug reportlab
```

### Running the App

```bash
# Initialise the database (first time only)
python fresh_setup.py

# Start the Flask development server
python "app (1).py"
```

Then open your browser at **http://127.0.0.1:5000**

> On Windows you can also double-click `run_script.bat`.

## 📖 Usage

### Student Flow

1. **Register** at `/register` to create an account
2. **Login** at `/login`
3. Fill in the **Admission Form** at `/admission` (uploads photo, ID proof, etc.)
4. **Pay Fees** at `/fees` — total is auto-calculated based on your course; download the PDF receipt after payment
5. **Register for Exams** at `/exam` — exams are filtered to your enrolled course
6. **View Results** at `/result` once the admin has entered your marks

### Admin Flow

1. Login with an admin account (set `role = 'admin'` directly in the DB for the first admin)
2. **Manage Exams** at `/admin/exams` — create exams with multiple subjects and schedule
3. **Manage Results** at `/admin/results` — enter marks, grade, CGPA, and pass/fail status for each student
4. **View Analytics** at `/analysis` — see result trends and pass/fail distribution charts
